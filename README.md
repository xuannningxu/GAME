# 旷野来信 / Wild Within

独立的中文动物人格测试 V1。原生 HTML、CSS、JavaScript，无需安装依赖、无需登录、无后端和统计脚本。所有照片保存在项目内。

## 功能

- 24道原创生活情境题，16种动物原型。
- 六维倾向：社交能量、探索倾向、行动节奏、共情关注、秩序偏好、自主取向。
- 主动物、第二相似动物、六维分数、优势、盲点、行动练习与相处建议。
- 可返回改答、刷新后续答、本机进度清除。
- PNG结果卡（含摄影署名）、带版本号的报告分享链接。
- 响应式布局，键盘操作和减少动画偏好支持。

## 本机预览

安装 Node.js 22 或以上，在项目文件夹执行：

```sh
npm start
```

打开 http://127.0.0.1:4173 。请通过 HTTP 预览，直接双击 HTML 会受到浏览器 ES 模块限制。

```sh
npm test
```

不需要 npm install。测试覆盖题目与维度完整性、正反向端点、16原型可达性、距离排序、无效输入、分享编码恢复与照片文件。

## GitHub Pages

仓库根目录应直接包含 index.html、app.js、data.js、credits.js、style.css 和 assets/，不要多套一层项目文件夹。

推荐最简单的部署：进入仓库 Settings → Pages，在 Build and deployment 中选 Deploy from a branch，分支 main、文件夹 / (root)，点击 Save。等待 GitHub Pages 构建完成后，打开设置页显示的网址。相对资源路径支持 /GAME/ 这样的项目子目录；结果通过 #v1=... 分享，无需配置服务器路由。

也可使用仓库提供的 `.github/workflows/pages.yml`：将 Pages Source 改成 GitHub Actions，然后进入 Actions → Deploy static site to Pages → Run workflow。工作流先运行测试，再上传仅包含静态页面与资源的产物。两种发布方式选一种即可。

## 评分

每维4题，其中2题反向。四个选项对应0、33、67、100分，反向题相反，求四题均值。与16个预设六维向量计算均方根距离：

```
distance = sqrt(sum((personal[i] - archetype[i])²) / 6)
```

距离最小者为主动物，次小者为第二相似动物；同距时按图鉴顺序排序。距离不等于概率或百分位。原型可在 data.js 中直接检查。动物为性格叙事比喻，量表未经心理测量学验证，仅用于娱乐与自我探索。

## 隐私与分享

答案仅存于浏览器 localStorage。访问分享链接不覆盖本机进度，点击修改分享报告时才保存。分享链接含24题的选项编码，接收者可还原全部答案；不是加密或匿名化。截图卡只显示结果和维度，不显示逐题答案。PNG照片署名随卡保留，照片和衍生图片按各自摄影许可使用。

## 参考与设计

参考公开网页 https://exoticflicker.github.io/cati/ 的单题、上一题、进度条与结果分享流程；没有复制题目、文案、照片、动画或代码。采用米白、森林绿、衬线标题与真实动物照片，题目页减少装饰，报告支持自由滚动。

参考页面已通过 HTTP 取得并检查源码；实际浏览器点击检查因工具无法确认网址而中断。项目 HTTP 服务已返回200，计分自动化检查通过。手机与桌面响应式样式已实现；真实设备视觉、完整浏览器作答、系统分享和PNG下载仍需人工验收，不能视为已经实测通过。

## 文件

- index.html：页面骨架。
- app.js：作答、进度、报告、分享与PNG绘制。
- data.js：全部题目、原型、计分与结果编解码。
- credits.js、CREDITS.md、assets/sources.json：摄影署名、原图链接及许可。
- server.js：仅本机预览，不是线上后端。
- test.mjs：核心功能检查。
